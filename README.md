# merlin-workshop
The modding toolkit for Tainted Grail: The Fall of Avalon

We recommend creating a fork of this repository to access the newest releases. If you are not familiar with Git, do not use GitHub’s autogenerated .zip to download the toolkit - this will not work. You can download it as a 7z file from the [releases section](https://github.com/AR-Questline/merlin-workshop/releases).

There is a [Wiki](https://github.com/AR-Questline/merlin-workshop/wiki) with tutorials on creating simple mods.
